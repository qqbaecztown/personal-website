# Am0r3 Photography Portfolio

A single-page photography portfolio built on the shadcn Next.js template.

Contact email: `baecztown@gmail.com`.

## Run locally

```bash
pnpm install
pnpm dev
```

## Image replacements

The current site uses free Unsplash photography as temporary assets. Replace these locations with your own work:

- Hero background in `app/page.tsx`
- The six `work` items in `app/page.tsx`, including title, category, and `src`
- Display name and contact email in `app/page.tsx` and `app/layout.tsx`

Recommended image sizes are 1600px on the long edge for work tiles and 2400px for the hero.
